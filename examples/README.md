# 실제로 보낸 요청과 메시지의 예

모델에게 보낸 글을 그대로 펼친 것이다. 본 실험의 요청은 `questline/prompting.py` 가 만들며, 아래 파일은 그 함수를 그대로 불러 만들었다.

| 파일 | 내용 |
|---|---|
| `request_M40.txt` | 라인 M40 의 생성 요청 전문. 시스템 역할 한 줄과 사용자 메시지(설정집 전문, 지시, 과제, 출력 형식)다. 조건 C1~C4 의 첫 생성은 모두 이 요청을 쓴다 |
| `feedback_C2_M40_claude_rep1.txt` | 조건 C2 에서 M40, Claude, 반복 1 의 첫 출력에 보낸 피드백. 물건의 소유자가 바뀐 지점의 오류 한 건이다 |
| `feedback_C2_M02_claude_rep1.txt` | 조건 C2 에서 M02, Claude, 반복 1 의 첫 출력에 보낸 피드백. 소유자가 바뀐 물건의 오류와 사망한 인물의 오류가 한 건씩 있다 |
| `message_C4.txt` | 조건 C4 에서 재생성 때 보낸 메시지. 모든 셀에서 같다 |

피드백 메시지는 검사기가 찾은 오류(`runs/questline/main/cells.jsonl` 의 해당 시도 `violations`)로 만든다. 이름과 조사 사이가 떨어진 것("서리 뿔피리 을")은 프로그램이 이름을 끼워 넣어 만든 글이라 그렇다.

C2 와 C4 의 재생성 요청은 처음 요청, 모델의 앞 출력, 위 메시지를 차례로 붙인 대화다. C3 의 재생성은 처음 요청만 새 seed 로 다시 보낸다.
